# Application artwork

`thunderbird-tray-amber.png` is the original master artwork used for the
application, settings window, connected tray state, desktop launcher, and
Thunderbird extension. `thunderbird-tray-unread.png` is its red-envelope unread
state. The `hicolor` and `extension/icons` files are resized derivatives.

The artwork was generated specifically for thunderbird-tray and does not use
or modify the Mozilla Thunderbird trademark or logo. It is distributed with
this project under `GPL-3.0-only`.
