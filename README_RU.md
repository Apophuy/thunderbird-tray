# thunderbird-tray

[English version](README.md)

`thunderbird-tray` — небольшое дополнение к Mozilla Thunderbird 156 и новее,
которое работает в системном трее Linux. Расширение Thunderbird на Manifest V3
передаёт состояние непрочитанных писем локальному процессу на Rust через Native
Messaging. Интерфейс трея не требует Qt или GTK; первой полностью поддерживаемой
средой станет KDE Plasma Wayland.

Это новая реализация, вдохновлённая пользовательским поведением Birdtray. Проект
не является форком Birdtray и не использует его исходный код или архитектуру.

Проект находится в активной разработке. Текущий вертикальный срез соединяет
расширение Thunderbird 156+ с локальным Rust-процессом и передаёт суммарное число
непрочитанных писем из папок «Входящие». Интерфейс трея пока не реализован.

## Требования

- Rust 1.85 или новее, включая `rustfmt` и `clippy`;
- Node.js 22.13 или новее и npm;
- Thunderbird 156 или новее для интеграционной проверки.

## Сборка и тестирование

```sh
cargo build --workspace
cargo test --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings

npm --prefix extension ci
npm --prefix extension run lint
npm --prefix extension test
npm --prefix extension run build
```

Подробности приведены в [руководстве разработчика](docs/development.md), а
границы компонентов и идентификаторы — в
[обзоре архитектуры](docs/architecture.md). Для локальной настройки права root
не требуются.

## Конфиденциальность

Источником истины об учётных записях, папках и непрочитанных письмах остаётся
Thunderbird. Расширение передаёт локальному процессу через Native Messaging
только идентификаторы и отображаемые имена учётных записей, а также суммарное
число непрочитанных писем во «Входящих». Темы и содержимое писем, адреса
отправителей и учётные данные не передаются. Сетевых соединений для этого нет.

## Текущие ограничения

- В общем счётчике учитываются только папки «Входящие».
- Интерфейс трея, переключатель языка и управление окнами рабочего стола будут
  реализованы на следующих этапах MVP.
- Поддерживается только Linux; первой целевой средой является KDE Plasma
  Wayland.
