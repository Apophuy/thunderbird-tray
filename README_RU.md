# thunderbird-tray

[English version](README.md)

`thunderbird-tray` — небольшое дополнение к Mozilla Thunderbird 156 и новее,
которое работает в системном трее Linux. Расширение Thunderbird на Manifest V3
передаёт состояние непрочитанных писем локальному процессу на Rust через Native
Messaging. Интерфейс трея не требует Qt или GTK; первой полностью поддерживаемой
средой станет KDE Plasma Wayland.

Это новая реализация, вдохновлённая пользовательским поведением Birdtray. Проект
не является форком Birdtray и не использует его исходный код или архитектуру.

Проект находится в активной разработке. Текущая реализация соединяет расширение
Thunderbird 156+ с локальным Rust-процессом и показывает суммарное состояние
непрочитанных писем из папок «Входящие» через StatusNotifierItem и нативное меню
DBusMenu без зависимости от графического тулкита.

## Требования

- Rust 1.85 или новее, включая `rustfmt` и `clippy`;
- Node.js 22.13 или новее и npm;
- Thunderbird 156 или новее для интеграционной проверки.

## Сборка и тестирование

```sh
cargo build --workspace
cargo test --workspace
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings

npm --prefix extension ci
npm --prefix extension run lint
npm --prefix extension test
npm --prefix extension run build
```

Подробности приведены в [руководстве разработчика](docs/development.md), а
границы компонентов и идентификаторы — в
[обзоре архитектуры](docs/architecture.md). Конфигурация и параметры командной
строки описаны в [отдельном руководстве](docs/configuration.md). Для локальной
настройки права root не требуются.

## Конфигурация

По умолчанию используется файл
`$XDG_CONFIG_HOME/thunderbird-tray/config.toml`, а если переменная не задана —
`~/.config/thunderbird-tray/config.toml`. Поддерживаются английский и русский
языки. Значение `language = "auto"` выбирает русский для русской системной
локали, а в остальных случаях — английский. Полный список начальных параметров
есть в [`packaging/config.example.toml`](packaging/config.example.toml).

Команда `thunderbird-tray doctor` выводит локализованную безопасную сводку
активной конфигурации без данных почты. Список параметров доступен через
`thunderbird-tray --help`.

## Интерфейс трея

Иконка и локализованный текст различают подключённое состояние, наличие новых
писем и отсутствие соединения. Нативное меню показывает текущее состояние
«Входящих», позволяет запросить полный свежий снимок и содержит сохраняемый
переключатель языка: «Автоматически», English и Русский. Пункт открытия
Thunderbird виден, но останется неактивным до реализации бэкенда запуска и
управления окнами.

Иконки встроены в нескольких размерах, поэтому основная часть интерфейса трея
не зависит от установленной темы значков. Оформление меню, навигацию с
клавиатуры и интеграцию с темой обеспечивает сама Plasma.

## Конфиденциальность

Источником истины об учётных записях, папках и непрочитанных письмах остаётся
Thunderbird. Расширение передаёт локальному процессу через Native Messaging
только идентификаторы и отображаемые имена учётных записей, а также суммарное
число непрочитанных писем во «Входящих». Темы и содержимое писем, адреса
отправителей и учётные данные не передаются. Сетевых соединений для этого нет.

## Текущие ограничения

- В общем счётчике учитываются только папки «Входящие».
- Открытие Thunderbird и управление его окнами будут реализованы на следующих
  этапах MVP.
- Поддерживается только Linux; первой целевой средой является KDE Plasma
  Wayland.
